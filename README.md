## Overview

This project analyzes customer behavior using the Customer Personality Analysis dataset from Kaggle. The objective is to apply data mining techniques to discover customer segments, support marketing decision-making, and optimize analytical models.

## Dataset

* Dataset: Customer Personality Analysis
* Source: Kaggle
* Records: 2240 customers
* Domain: Marketing & Customer Analytics

The dataset contains customer demographics, purchasing behavior, campaign responses, and spending patterns across multiple product categories.

## Project Tasks

### 1. Exploratory Data Analysis (EDA)

* Data exploration and statistical analysis
* Feature distribution visualization
* Correlation analysis
* Customer behavior insights

### 2. Data Preprocessing

* Handling missing values
* Outlier detection and treatment
* Categorical feature encoding
* Feature scaling and transformation

### 3. K-Medoids Clustering

* Customer segmentation
* Optimal cluster selection using Elbow Method and Silhouette Score
* Cluster profile analysis

### 4. Hierarchical Clustering

* Comparison of different linkage methods
* Customer group identification
* Cluster interpretation

### 5. Fuzzy Logic System

* Fuzzy membership functions
* Rule-based decision system
* Customer evaluation and recommendation generation

### 6. Genetic Algorithm Optimization

* Parameter optimization
* Fitness evaluation
* Performance comparison with baseline results

### 7. Integrated System

A complete pipeline combining preprocessing, clustering, fuzzy logic, and genetic optimization to generate meaningful business insights.
